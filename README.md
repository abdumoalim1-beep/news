# مدونة عبدالله معلم

مدونة شخصية عربية مبنية بـ [Next.js](https://nextjs.org) (App Router + TypeScript)، منقولة من تصميم أولي أُنشئ في Claude Design.

## الصفحات

- `/` — الصفحة الرئيسية (نبذة، الفئات، أحدث المقالات)
- `/articles` — كل المقالات (مع فلترة بالفئة عبر `?category=...`)
- `/articles/[id]` — صفحة المقال
- `/admin` — لوحة التحكم (محمية بكلمة سر) لإضافة/تعديل/حذف المقالات

## البدء

```bash
npm install
npm run dev
```

افتح http://localhost:3000

## لوحة التحكم

لوحة التحكم محمية بكلمة سر تُقرأ من متغير بيئة `ADMIN_PASSWORD` — لا توجد كلمة سر مكتوبة في الكود.

1. انسخ `.env.local.example` إلى `.env.local`
2. عدّل `ADMIN_PASSWORD` إلى كلمة سر قوية
3. أعد تشغيل الخادم

بدون ضبط `ADMIN_PASSWORD`، ستظهر صفحة `/admin` رسالة توضح أن كلمة السر غير مضبوطة، ولن يُسمح بتسجيل الدخول.

## تخزين المحتوى

المقالات تُخزَّن كملفات JSON داخل `content/articles/*.json` — كل مقال في ملف مستقل. عند الحفظ من لوحة التحكم، يكتب الخادم الملف مباشرة على القرص عبر مسارات API (`app/api/admin/...`). لا توجد قاعدة بيانات خارجية.

الصور المرفوعة من لوحة التحكم تُحفظ في `public/uploads/`.

> ملاحظة: إذا نشرت الموقع على منصة بدون نظام ملفات دائم (serverless بحت)، فإن الكتابة إلى `content/articles` و `public/uploads` وقت التشغيل لن تُحفظ بين عمليات النشر. يعمل هذا الإعداد بشكل موثوق على استضافة بها نظام ملفات دائم (خادم عادي، أو حاوية، أو VPS).

## البناء للإنتاج

```bash
npm run build
npm run start
```

## المصدر

تم نقل التصميم من حزمة تسليم (handoff bundle) صادرة عن Claude Design، وأُعيد بناؤه بالكامل كتطبيق Next.js حقيقي (بدلاً من نموذج HTML/CSS/JS الأولي الذي كان يخزّن البيانات في localStorage بالمتصفح).
