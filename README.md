# مدونة عبدالله معلم

مدونة شخصية عربية مبنية بـ [Next.js](https://nextjs.org) (App Router + TypeScript)، منقولة من تصميم أولي أُنشئ في Claude Design.

## الصفحات

- `/` — الصفحة الرئيسية (نبذة، الفئات، أحدث المقالات)
- `/articles` — كل المقالات (مع فلترة بالفئة عبر `?category=...`)
- `/articles/[id]` — صفحة المقال
- `/admin` — لوحة التحكم (محمية بكلمة سر) لإضافة/تعديل/حذف المقالات

## البدء محليًا

```bash
npm install
cp .env.local.example .env.local   # وعدّل ADMIN_PASSWORD
npm run dev
```

افتح http://localhost:3000

## لوحة التحكم

لوحة التحكم محمية بكلمة سر تُقرأ من متغير بيئة `ADMIN_PASSWORD` — لا توجد كلمة سر مكتوبة في الكود. بدون ضبط هذا المتغير، ستظهر صفحة `/admin` رسالة توضح أن كلمة السر غير مضبوطة، ولن يُسمح بتسجيل الدخول.

## تخزين المحتوى

المقالات تُخزَّن كملفات JSON داخل `content/articles/*.json` — كل مقال في ملف مستقل. الصور المرفوعة من لوحة التحكم تُحفظ في `public/uploads/`. لا توجد قاعدة بيانات خارجية.

طريقة الكتابة تختلف حسب البيئة:

- **محليًا (`npm run dev`)**: الحفظ يكتب مباشرة على القرص.
- **على فيرسل (أو أي استضافة serverless)**: القرص غير دائم، فالحفظ يرفع commit مباشرًا إلى مستودع GitHub عبر GitHub API، ثم يُعيد فيرسل النشر تلقائيًا خلال حوالي دقيقة. هذا يعمل تلقائيًا بمجرد ضبط متغيرات `GITHUB_TOKEN` و `GITHUB_REPO` (انظر أدناه) — بدونها، أي محاولة حفظ على فيرسل ستفشل بدل أن تُفقد بصمت.

## النشر على فيرسل (Vercel)

### 1. اربط المستودع

في [vercel.com](https://vercel.com) أنشئ مشروعًا جديدًا واستورد مستودع `abdumoalim1-beep/news` على فرع `main` (أو الفرع الذي تريد نشره). فيرسل يتعرّف تلقائيًا على أنه مشروع Next.js ولا يحتاج إعدادات بناء إضافية.

### 2. أنشئ GitHub Token للحفظ من لوحة التحكم

1. اذهب إلى GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate new token
2. اختر الوصول لمستودع `abdumoalim1-beep/news` فقط (Repository access → Only select repositories)
3. من Permissions فعّل **Contents: Read and write**
4. انسخ التوكن (يظهر مرة واحدة فقط)

### 3. أضف متغيرات البيئة في إعدادات المشروع على فيرسل

| المتغير | القيمة |
|---|---|
| `ADMIN_PASSWORD` | كلمة سر قوية تختارها للوحة التحكم |
| `GITHUB_TOKEN` | التوكن الذي أنشأته في الخطوة السابقة |
| `GITHUB_REPO` | `abdumoalim1-beep/news` |
| `GITHUB_BRANCH` | اسم الفرع الذي ربطته بفيرسل (مثلًا `main`) |

بعد إضافتها أعد نشر المشروع (Redeploy) مرة واحدة لتُقرأ المتغيرات.

### ملاحظات مهمة حول النشر على فيرسل

- **الحفظ/الحذف/رفع الصور من لوحة التحكم يرفع commit مباشرًا إلى الفرع المضبوط في `GITHUB_BRANCH`**، ثم يُعيد فيرسل بناء الموقع تلقائيًا. تظهر التغييرات على الموقع المباشر خلال دقيقة تقريبًا، وليس فوريًا — تُظهر لوحة التحكم رسالة توضح ذلك بعد كل حفظ.
- زر **"معاينة"** أثناء التحرير يعرض معاينة فورية من المسودة نفسها (بدون انتظار النشر)، بدل فتح الصفحة الحقيقية التي قد لا تكون محدَّثة بعد.
- حجم الصورة المرفوعة محدود بـ 4 ميغابايت (حد طلبات فيرسل للدوال).
- بدون ضبط `GITHUB_TOKEN`/`GITHUB_REPO` على فيرسل، ستفشل عمليات الحفظ/الحذف/الرفع من لوحة التحكم برسالة خطأ واضحة بدل أن تُفقد التغييرات بصمت.

## البناء للإنتاج محليًا

